Working directory for every command below:
  The root of your lingbot-depth-realsense checkout. All project paths are relative.

First install the environment, download weights, and clone the fixed TensorRT
reference repository using README.md. All eight official examples and the
optimization tools referenced below are included in this repository.

Build the engine for this GPU:
  mkdir -p result/logs result/optimization
  env -u PYTHONPATH HF_HUB_OFFLINE=1 .venv-optimization/bin/python -u \
    result/optimization/reference-lingbot-depth-trt/tools/export_trt.py \
    --model checkpoints/lingbot-depth-v0.5/model.pt --capture examples/0 \
    --precision fp16 --num-tokens 2000 --width 640 --height 480 \
    --work-dir result/optimization/reference-trt-nt2000-fp16 \
    --skip-ort --workspace-gb 4 --tactic-gb 2 --trt-warmup 10 --trt-runs 100 \
    > result/logs/reference-trt-export.log 2>&1

Run the full eight-scene comparison and validation:
  env -u PYTHONPATH HF_HUB_OFFLINE=1 TORCHINDUCTOR_COMPILE_THREADS=2 \
    .venv-optimization/bin/python -u tools/optimization/probe_reference_trt.py \
    > result/logs/reference-trt-benchmark.log 2>&1

Save depth arrays for visual comparison:
  env -u PYTHONPATH HF_HUB_OFFLINE=1 .venv-optimization/bin/python -u \
    tools/optimization/prepare_visual_inputs.py

Render the eight-scene visual comparison:
  env -u PYTHONPATH MPLBACKEND=Agg .venv-optimization/bin/python \
    tools/optimization/plot_best_cases.py

Timing convention:
  Model and preprocessed inputs are resident on GPU.
  Synchronize CUDA before and after each host-wall-clock measurement.
  Baseline: original level 3 BF16, 20 measured runs per scene.
  TensorRT modes: 50 measured runs per scene after warmup.
  Input-buffer copies, startup, model loading, ONNX export, engine construction,
  compilation, preprocessing, CPU/GPU transfer, and file I/O are excluded.

Output differences from the original model:
  Variable depth-token masking is disabled.
  RGB interpolation antialias is disabled.
  The engine only returns depth, without the original validity-mask head.
  Point clouds are projected from the unmasked depth outside the engine.
  Ordinary TensorRT and CUDA Graph depth outputs must match exactly.
  Reported depth differences are prediction consistency checks. The bundled
  examples have no ground-truth depth, so these checks do not measure accuracy.

The TensorRT engine is built locally; rebuild it when changing GPU, TensorRT
version, input dimensions, token count, or model weights.

Measured results on 2026-10-13 (RTX 5060 Ti):
  Original level 3 BF16:                              147.267 ms
  TensorRT FP16 depth engine:                          67.767 ms
  TensorRT FP16 plus GPU point-cloud projection:       67.890 ms
  TensorRT CUDA Graph plus compiled projection:        67.907 ms
  Combined speedup versus original level 3:             2.169 x
  Combined rate derived from mean latency:             14.726 frames/second
  ONNX export: 3.947 seconds; TensorRT build: 50.170 seconds.
  Engine size: 646,536,156 bytes (616.585 MiB).
  Target 2000 tokens produces a 39 x 52 patch grid (2028 patches) at 640 x 480.

CUDA Graph and compiled projection add no measurable speed benefit over plain
TensorRT plus projection in this run (difference: 0.017 ms). Both preserve the
same tested TensorRT depth outputs; neither restores the original output mask.

Validation status: PASS, 8/8 scenes.
  All TensorRT outputs are finite positive depth tensors of shape [1, 480, 640].
  Point clouds have shape [1, 480, 640, 3] and Z agrees exactly with depth.
  CUDA Graph and ordinary TensorRT depth predictions are exactly equal.
  Mean relative difference versus reference PyTorch FP16: 0.019%-0.131%.
  Mean relative difference versus original level 3 BF16: 0.288%-0.649%.
  Scene 3 has the largest baseline differences: P99 1.28125 m, max 6.14375 m.
  These statistics only compare pixels with finite positive depth in both paths.
  Small mean differences do not establish per-pixel equivalence or accuracy.
